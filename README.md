## 🇬🇧 English

### 📖 What it does
An automated, real-time traffic safety compliance monitoring dashboard powered by a custom YOLOv5 object detection model.

### 🛠️ Technologies
**Python, YOLOv5, OpenCV, Flask**

### 💻 How to install & run locally
```bash
run_safecity.bat
```
